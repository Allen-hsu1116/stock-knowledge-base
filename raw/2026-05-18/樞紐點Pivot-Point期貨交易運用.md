# 樞紐點Pivot Point是什麼？期貨交易如何運用？

樞紐點（Pivot Point）策略是一種廣泛運用於期貨交易的技術分析方法，它可以幫助交易者更好地理解市場走勢並做出明智的交易決策。

## 什麼是樞紐點？

樞紐點（Pivot Point）是一種技術分析工具，被廣泛應用於期貨交易中，以幫助交易者識別關鍵的支持位、阻力位和樞紸點水平。這些價格水平提供了交易者在市場中制定交易策略和決策的重要參考點。

樞紸點是基於前一個交易日的價格變動來計算的，具體計算如下：

**樞紸點（Pivot，P）=（昨日最高價 + 昨日最低價 + 昨日收盤價）/ 3**

樞紸點還包括三個支持位和三個阻力位：

- 第一個阻力位（R1）=（2 × P）– 昨日最低價
- 第一個支持位（S1）=（2 × P）– 昨日最高價
- 第二個阻力位（R2）= P +（昨日最高價 – 昨日最低價）
- 第二個支持位（S2）= P –（昨日最高價 – 昨日最低價）
- 第三個阻力位（R3）= 昨日最高價 + 2 ×（P – 昨日最低價）
- 第三個支持位（S3）= 昨日最低價 – 2 ×（昨日最高價 – P）

| 水平 | 公式 |
|------|------|
| 逆轉買進 HBOP (R3) | 昨日最高價 + 2 × (P – 昨日最低價) |
| 阻力2 R2 | P + (昨日高價 - 昨日低價) |
| 阻力1 R1 | P × 2 - 昨日低價 |
| Pivot P | (昨日高價 + 昨日低價 + 昨日收盤價) ÷ 3 |
| 支撐1 S1 | P × 2 - 昨日高價 |
| 支撐2 S2 | P - (昨日高價 - 昨日低價) |
| 逆轉賣出 LBOP (S3) | 昨日最低價 - 2 × (昨日最高價 - P) |

## 如何運用樞紸點在期貨交易上？

- **支持位和阻力位交易**：當價格接近支持位時，考慮建立多頭頭寸，並將支持位作為停損點。相反，當價格接近阻力位時，建立空頭頭寸，並使用阻力位作為停損點。

- **趨勢追蹤**：如果價格突破樞紸點，這可能表明趨勢的開始。交易者可以觀察價格是否持續超越樞紸點，以判斷市場的趨勢方向。

- **逆勢交易**：在S2～R2的區間內會以逆勢交易為主，但突破S3或R3則會順勢去做多或做空。

## 其他補充

樞紸點策略雖然強大，但不是萬能的。交易者應該謹慎使用樞紸點，並在實際交易之前進行充分的研究和測試。此外，結合其他技術分析工具和風險管理策略可以提高交易成功的機會。
