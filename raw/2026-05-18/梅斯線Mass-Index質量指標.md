## taindicators 原文

Mass Index 是由Donald Dorsey 開發，目的是通過測量高與低價格範圍的縮小和擴大，找出趨勢反轉的指標。高低價格範圍擴大，Mass Index 上升，高低價格範圍收窄，Mass Index 下降。

一般參數設定為25天。可視需要縮短週期至12天。 參考MASS指標時，須同時觀察K線圖走勢，並且在圖表上，繪製一條股價的9天移動平均線。

觀察MASS Index指標的曲線圖時，必須特別注意其曲線「凸出的部分」。當股價的高低波幅差距擴大，或者股價的動量指標急速噴出時，都會造成曲線形成「凸出的部分」。

MASS Index 將每日的價差波幅，以指數平均的方式加以平滑，以便觀察它波帶寬窄的程度。一般而言，當MASS Index 高於25時，代表價差波幅擴大。當MASS Index 低於25時，代表價差波幅狹窄。但是，所謂「凸出的部分」，經常是價差波幅瞬間大幅擴張所造成的。由於衝擊的力量過於猛烈，造成MASS曲線向上穿越27，暗示股價波帶的寬度已擴增至一定極限，近期內反轉的可能性增加。

觀察MASS曲線的「凸出的部分」訊號時，必須同時觀察K線圖走勢，並且在圖表上，搭配一條9天的移動平均線。根據移動平均線移動的方向，決定進場買入或者退場賣出。

- MASS Index 向上穿越27,隨後又掉頭跌落26.5。當時，如果股價的9天移動平均線，正處於上升狀態，代表多頭行情即將反轉下跌。
- MASS Index 向上穿越27,隨後又掉頭跌落26.5。當時，如果股價的9天移動平均線，正處於下跌狀態，代表空頭行情即將反轉上漲。

## MBA智庫百科原文

梅斯線是Donald Dorsey累積股價波幅寬度之後，所設計的震蕩曲線。本指標最主要的作用，在於尋找飆漲股或者極度弱勢股的重要趨勢反轉點。

MASS指標是所有區間震蕩指標中，風險係數最小的一個。由於股價高低點之間的價差波帶，忽而寬忽而窄，並且不斷的重覆迴圈。利用這種重覆迴圈的波帶，可以準確地預測股價的趨勢反轉點，一般市場上的技術指標，通常沒辦法具備這方面的功能。觀察MASS指標的曲線圖時，必須特別注意其曲線「凸出的部分」。當股價的高低波幅差距擴大，或者股價的動量指標急速噴出時，都會造成曲線形成「凸出的部分」。

為了將股價的波幅差距，固定成一個範圍模式。MASS指標將每日的價差波幅，以指數平均的方式加以平滑，以便觀察它波帶寬窄的程度。一般而言，當MASS高於25時，代表價差波幅擴大。當MASS低於25時，代表價差波幅狹窄。但是，所謂「凸出的部分」，經常是價差波幅瞬間大幅擴張所造成的。由於衝擊的力量過於猛烈，造成MASS曲線向上穿越27，暗示股價波帶的寬度已擴增至一定極限，近期內反轉的可能性增加。

計算公式：
1、AHL＝DIF的9天指數平均數。
2、BHL＝AHL的9天指數平均數。
3、MI = Σ(AHL/BHL, N)
4、一般參數設定為25天。可視需要縮短周期至12天。
5、參考MASS指標時，須同時觀察K線圖走勢，並且在K線圖上，繪製一條股價的9天移動平均線。

應用原則：
1、MASS曲線向上穿越27,隨後又掉頭跌落26.5。當時，如果股價的9天移動平均線，正處於上升狀態，代表多頭行情即將反轉下跌。
2、MASS曲線向上穿越27,隨後又掉頭跌落26.5。當時，如果股價的9天移動平均線，正處於下跌狀態，代表空頭行情即將反轉上漲。
3、MASS曲線低於25的股票，一般不具有投資機會。

由於梅斯線比較敏感，因此有必要對其參數進行修正。將梅斯線參數由默認值25改為60，搭配的移動平均線由9改為25，可過濾掉一些不必要的信號，提供準確性。

## 程式交易≠Holy Grail 原文

EasyTrader ArtNo 137

梅斯線是Donald Dorsey累積股價波幅寬度之後，所設計的震蕩曲線。本指標最主要的作用，在於尋找飆漲股或者極度弱勢股的重要趨勢反轉點。

MASS指標是所有區間震蕩指標中，風險係數最小的一個。由於股價高低點之間的價差波帶，忽而寬忽而窄，並且不斷的重覆迴圈。利用這種重覆迴圈的波帶，可以準確地預測股價的趨勢反轉點，一般市場上的技術指標，通常沒辦法具備這方面的功能。觀察MASS指標的曲線圖時，必須特別註意其曲線「凸出的部分」。當股價的高低波幅差距擴大，或者股價的動量指標急速噴出時，都會造成曲線形成「凸出的部分」。

[台指期 30分K 留倉 2004/3/31 ~2014/3/31 交易成本 1200]

程式碼：
input:Length(9),MassSum(25),Band(27),Trigger(26.5) ;
Vars:AHL(0),BHL(0),Mass(0);
AHL = XAverage(Range,Length) ;
BHL = XAverage(AHL,Length) ;
if BHL <> 0 then Value1 = AHL/BHL ;
Mass = Summation(Value1,MassSum) ;
Plot1(Mass,"MI") ;
Plot2(Band,"Band") ;
Plot3(Trigger,"Trigger") ;
