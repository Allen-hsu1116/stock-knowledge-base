# ROC - Rate Of Change (%) 變動率指標

**來源**：https://www.taindicators.com/roc/
**日期**：2026-05-18
**主題**：技術分析

---

## 計算方法

```
當天收盤價 - n 天前收盤價
ROC(n) = ----------------------- * 100
         n 天前收盤價

n 的參數一般採用12天及25天做為間隔週期
```

## 應用例子

這個指標圍繞0軸線上下震盪。它的用法與其它震盪指標類似，通過尋找不斷增高的底部或者不斷降低的高點、牛熊背馳和穿越0軸線來獲得買賣信號。

ROC 指標在 0線上下運動時容易產生盤局現象，此時可能產生干擾信號，因此應結合其它技術分析方法使用。

### 超買 / 超賣

ROC 上升到極高位置時，指標達到超買水平，產生賣出信號。ROC 下降到極低位置時，指標達到超賣水平，產生買入信號。

### 趨勢

ROC 與股價從低位同步上升，表示短期有望觸底反彈或短期股價會有繼續上漲趨勢。ROC 與股價從高位同時下降，表示短期警惕做頭回落或短期股價會有繼續下跌趨勢。

### 背馳訊號

當股價創新高時，ROC 未配合上升，不能創新高，出現背離，表示上漲動能減弱，頭部正在形成。當股價創新低時，ROC 未配合下降，不能創新低，出現背離，顯示下跌動能減弱，底部正在形成。
