# ROC指標完整教學，ROC變動率指標參數設定與用法

**日期**：2026-05-18
**主題**：技術分析

---

ROC 指標全名為變動率指標（Rate Of Change，簡稱 ROC），是一種反映股票或其他金融商品價格變化速度的技術指標。雖然 ROC 指標嚴格來說並不是一個具有分析性質的指標，但它可以反映出不同時間段內的價格變化，以判斷市場是否處於超買或超賣的情況。

## ROC 指標原理

由於 ROC 指標是衡量資產價格變化速度的一種技術指標，它是根據特定時間區間內商品價格的變化率而計算出來。

也就是說，ROC 指標的原理是透過計算出股票或其他金融產品的收盤價格變化速率，從而提供有關趨勢變化的訊息。藉此幫助交易者確定商品價格趨勢的強度和變化的方向，從而研判買進與賣出的時機點。

## ROC 指標公式

ROC = 〔（當日收盤價 － n 天前的收盤價）〕／ n 天前的收盤價 x 100

其中，n 代表的是當日價格與幾天前的價格做比較，所以可以根據使用者的需求進行調整。

一般來說，n 值如果越小，意味著 ROC 指標對於趨勢反應更靈敏，適合短線交易者使用；n 值如果越大，則代表 ROC 指標對於趨勢的反應越慢，適合長線交易者使用。

## ROC 指標優缺點

ROC 指標的優點在於能夠直觀地反映出市場是否處於超買或超賣的狀況，從而讓交易者能夠更精準的掌握進出場時機點。同時，它也能夠根據投資人的交易偏好，設置不同的時間框架，例如短期到長期皆可通用，以滿足投資者擬定不同週期的交易策略。

最後一點，ROC 指標還可以用來確認趨勢線的斜率，以及確認支撐和阻力位，更有助於投資人預測商品的未來價格走勢。

然而，由於 ROC 指標主要用於衡量價格變化的速度，忽略了交易量和其他因素的影響，因此提供的訊息可能不夠全面。除此之外，ROC 指標是根據過去的價格變化來計算，當市場處於橫盤或者過度震盪的時候，就會非常容易出現假訊號。

## ROC 指標怎麼看

ROC 指標主要是用來比較金融商品在不同時間段內的價格變化，來判斷是有超買或超賣的情況。因此使用上會以 0 當作基準值，當 ROC 指標值大於 0 時，表示價格正處於上漲階段；當 ROC 指標值小於 0 時，表示價格正處於下跌階段。

同時，當 ROC 指標值處於一個相對高點時，可以視為超買狀態，通常是價格即將下跌的訊號；當 ROC 指標值處於一個相對低點時，可以視為超賣狀態，通常是價格即將上漲的訊號。

由此可知，ROC 指標應用方法可以總結為以下兩點：

- 確認趨勢：在使用 ROC 指標進行技術分析時，當 ROC 線處於基準線之上時，可以認為是一個買方趨勢；反之，當 ROC 線處於基準線之下時，則可以認為是一個賣方趨勢。

- 確認反轉訊號：當商品價格接近支撐或阻力位時，投資人可以使用 ROC 指標來確認是否有趨勢反轉的訊號。當 ROC 值處於一個相對高點或相對低點的狀態時，則代表未來的趨勢有很大機率即將反轉。

## 結論

ROC 指標是一個淺顯易懂的技術分析工具，不僅能夠反映商品價格的變化，還可以判斷市場的買賣趨勢情況。

只是在實際應用中，不建議單純依賴 ROC 指標來擬定交易策略，最好還是可以搭配其他的技術分析工具一起使用，例如均線或 MACD 等指標，才能夠確保完整性。
