## 法人換股行為的核心邏輯

法人不是盲目買賣，每一次進出背後都有明確的邏輯：追求相對報酬最大化、符合投資規範限制、及回應贖回或申购壓力。理解法人換股的原因，就能搶在趨勢前面部署。

### 三大法人換股動機

**外資換股動機**
1. **產業景氣循環**：依據全球產業景氣調整持股比重，景氣復甦加碼景氣敏感股、景氣下行轉進防禦型
2. **匯率因素**：新台幣升值時外資匯入資金增加，傾向加碼大型權值股；貶值時可能減碼或轉進出口受惠股
3. **指數調整**：MSCI、FTSE等指數成分股調整直接驅動被動資金換股
4. **跨市場比較**：外資全球配置，台股相對吸引力下降時資金轉往其他市場

**投信換股動機**
1. **績效競爭**：同類基金績效排名壓力，落後大盤時更積極換股追漲
2. **停損機制**：持股虧損超過一定比例（通常10-15%）觸發風控停損，資金轉向強勢股
3. **季底作帳**：季底拉抬已持股美化績效，同時賣出虧損股認列損失
4. **基金規模變化**：申購量大增需要快速建倉，贖回量大增被迫減碼

**自營商換股動機**
1. **避險需求**：權證避險買超的隔日賣出是最大換股來源
2. **做市義務**：造市商需維持報價流動性，股價劇烈波動時調整部位
3. **自營操作**：自營部位操作時間極短，通常1-3天完成一輪進出

## 類股輪動的四大模式

### 模式一：景氣循環輪動
景氣從復甦→擴張→趨緩→衰退四階段，法人資金在不同類股間移轉：
- **復甦期**：科技成長股→原物料→金融
- **擴張期**：消費→工業製造→科技維持
- **趨緩期**：防禦型（電信、公用事業）→高殖利率→現金
- **衰退期**：防禦型維持→現金比例升高→等待復甦訊號

### 模式二：消息面驅動輪動
重大政策或事件驅動法人快速換股：
- FED降息預期升溫→金融股承壓、科技股受惠
- 地緣政治緊張→軍工概念股受惠、觀光航運承壓
- 新技術突破（AI、車用晶片）→相關供應鏈輪動

### 模式三：籌碼面驅動輪動
法人本身籌碼集中度過高時的被迫換股：
- 單一類股持股超過基金規範上限（通常20-25%），被迫減碼轉進其他類股
- 外資對單一個股持股比例接近上限（外資持股上限個股），買盤消失
- 當沖比重過高個股法人轉向低當沖比重標的

### 模式四：技術面驅動輪動
均線排列與技術指標變化影響法人選股：
- 類股指數跌破季線，投信系統性減碼該類股
- 類股指數領先大盤突破前高，法人加碼領漲類股
- 布林通道收斂後突破方向決定法人類股選擇

## 法人換股信號判讀實戰

### 信號一：類股買賣超比例變化
觀察三大法人在各類股的買賣超佔大盤買賣超比例：
- 外資連續3天買超集中特定類股（佔外資總買超>50%），該類股輪動啟動機率高
- 投信連續買超特定類股且買超金額佔投信總買超>30%，中期趨勢確認
- 自營商類股買超短期波動大，不具參考價值

### 信號二：法人持股比例變化
追蹤法人對各類股的持股比例變化：
- 外資對類股持股比例從低檔（<15%）連續3個月上升，中長期翻多訊號
- 投信對類股持股比例持續創新高（>10%），強勢類股確認
- 外資對類股持股比例從高檔（>30%）連續下降，中期看空

### 信號三：類股資金流向比率
計算流入特定類股的法人資金佔總法人資金比重：
- 資金流向比率 = 該類股法人買超金額 / 全市場法人買超金額
- 比率>20%且持續3天以上，資金明確轉向該類股
- 比率<5%且持續5天以上，該類股被法人遺棄

### 信號四：類股輪動速度指標
用類股輪動速度判斷市場格局：
- 輪動速度快（2-3天一個主流）：盤整格局，法人試水溫
- 輪動速度慢（1-2週一個主流）：趨勢行情，法人集中火力
- 無明確輪動（所有類股齊漲齊跌）：系統性風險或大行情啟動

## 實戰操作策略

### 策略一：跟著法人換股方向走
1. 每日盤後追踪三大法人類股買賣超
2. 找出連續3天買超金額最大的類股
3. 在該類股中挑選法人買超最多的個股
4. 搭配技術面確認（均線多頭排列、帶量突破）

### 策略二：提前部署法人可能換股的類股
1. 觀察景氣領先指標判斷景氣位置
2. 根據景氣位置預判下一個法人可能加碼的類股
3. 在法人尚未大量進場前先建立部位
4. 法人開始買超時加碼

### 策略三：法人換股潮中的防守
1. 當法人大量賣超特定類股時，不急著接刀
2. 法人賣超持續3天以上才可能是趨勢而非單日調節
3. 法人賣超但股價不跌（利空不跌），可能是換股而非看空
4. 法人賣超且股價破位（跌破支撐），趕緊跟著減碼

## 注意事項

1. **法人換股不等於股價方向**：法人買超類股不一定漲、賣超不一定跌，仍需搭配技術面與基本面確認
2. **單日數據噪音大**：法人的單日類股買賣超容易受大單影響，至少觀察3天趨勢
3. **外資避險部位干擾**：外資期貨避險調整可能誤導換股判斷，需排除避險交易
4. **投信季底作帳扭曲**：季底前2週的類股買賣超數據因作帳而失真
5. **類股定義差異**：不同券商對類股分類方式不同，比較時需注意一致性
6. **小型股輪動更快速**：小型類股的法人換股頻率更快、持續時間更短，操作難度更高
