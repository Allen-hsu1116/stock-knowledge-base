**來源**：綜合整理自現有知識庫素材與實戰經驗
**日期**：2026-05-20
**主題**：籌碼面分析

## 融資追繳機制完整解析

### 追繳觸發條件

融資維持率低於130%，券商即發出追繳通知。

融資維持率 = 股票現值 ÷ 融資金額 × 100%

以100元融資買進上市股票為例：
- 自備款：40%（4萬）
- 融資金額：60%（6萬）
- 原始維持率：10萬 ÷ 6萬 = 166.67%
- 跌至78元：7.8萬 ÷ 6萬 = 130%（觸發追繳）

### 追繳流程時間軸

| 時間 | 事件 | 投資人動作 |
|------|------|-----------|
| T日 | 維持率跌破130%，券商發出追繳通知 | 收到通知 |
| T+1日 | 緩衝期第一天 | 準備資金或抵押品 |
| T+2日收盤前 | 緩衝期截止 | 必須補繳至166%以上，或至少130%以上 |
| T+3日 | 未補繳者，券商強制賣出（斷頭） | 被迫出場 |

### 追繳補繳的三種結果

1. **補到166%以上**：追繳令完全撤銷，最安全
2. **補到130%~166%**：追繳令不撤銷，之後再跌破需「當日」補繳（沒有2天緩衝）
3. **未補或補不到130%**：T+3強制賣出 = 斷頭

### 「每日盯盤」的陷阱

只補到130%~166%的投資人最容易忽略的風險：追繳令不撤銷，每天收盤都會重新計算維持率。只要盤中又低於130%，就要「當日下午」補錢，不再有2天緩衝。很多融資戶以為補了錢就安全，結果隔天再跌又被迫斷頭。

## 斷頭連鎖效應（多殺多）

### 連鎖反應機制

```
股價下跌
  → 融資維持率跌破130%
    → 券商發出追繳通知
      → 融資戶無力補繳
        → 券商T+3強制賣出（斷頭）
          → 大量賣壓湧入市場
            → 供過於求，股價續跌
              → 更多融資維持率跌破130%
                → 更多斷頭、更多賣壓
                  → 惡性循環（多殺多）
```

### 連鎖效應的數學

假設某股融資餘額5000張，股價連續2根跌停：

- 第1根跌停：100 × 0.9 = 90元，維持率 = 9萬 ÷ 6萬 = 150%
- 第2根跌停：90 × 0.9 = 81元，維持率 = 8.1萬 ÷ 6萬 = 135%
- 第3根跌停：81 × 0.9 = 72.9元，維持率 = 7.29萬 ÷ 6萬 = 121.5%（低於130%，追繳）

只要連續3根跌停板，融資戶就會面臨追繳。如果融資餘額高（例如融資使用率>60%），追繳潮一啟動，券商不計成本拋售，很容易打到跌停，形成無量跌停的死亡螺旋。

### 2025年4月實戰案例

台股單日下跌2,065點（跌幅9.6%），大盤融資維持率降至133.8%，低於130%的個股高達589檔，形成連環追繳潮。這是近年最嚴重的融資斷頭連鎖效應。

### 股災三階段

1. **點火階段**：外部因素（政策、消息、國際股市）引發下跌
2. **融資斷頭潮**：維持率跌破130%，追繳→斷頭→更多賣壓
3. **流動性風險**：無量跌停，想賣賣不掉，市場信心崩潰

只要流動性風險未解，股市很難見底。要等融資清洗完畢、市場呈現死水一段時間、信心回穩又開始量增時，才是底部訊號。

## 整戶擔保維持率

### 什麼是整戶擔保維持率

券商不是看單一股票的維持率，而是看整個帳戶的「整戶擔保維持率」：

整戶擔保維持率 = 帳戶內所有擔保品市值 ÷ 整戶融資金額 × 100%

這意味著：
- 你A股票賺錢，可以掩護B股票的虧損
- 但如果整戶維持率跌破130%，全部部位都會被追繳
- 一檔股票斷頭，可能拖累整個帳戶

### 整戶維持率的風險傳導

```
B股票大跌
  → B維持率低
    → 整戶維持率下降
      → A股票雖然賺錢，但整戶被追繳
        → 被迫賣A來救B（或被迫全部斷頭）
          → A股票也下跌
            → 連鎖效應擴散
```

## 從外部觀察融資斷頭訊號

### 個股層面

1. **融資使用率>60%**：高風險警區，股價跌20%就可能斷頭
2. **融資維持率接近130%**：追繳壓力浮現
3. **融資餘額突然大減**：斷頭已在發生
4. **連續跌停+融資高**：多殺多最危險的組合

### 大盤層面

1. **大盤融資維持率<140%**：系統性風險升溫
2. **大盤維持率<130%**：大規模追繳潮啟動
3. **融資餘額急降+成交量暴增**：恐慌性出清（可能是底部）
4. **融資餘額穩定+維持率低**：散戶撐著沒跑，反彈機率較高

### 反轉訊號辨識

融資斷頭潮的底部不是V型反轉，而是：
1. 融資餘額大幅清洗（減少30%~50%）
2. 成交量從暴增轉為量縮
3. 出現紅K線（收盤>開盤）
4. 法人開始買超承接

**關鍵心法**：不要在斷頭潮正烈時接刀。等融資清洗完畢、量縮紅K出現，才是進場時機。

## 自保策略

### 融資操作的安全守則

1. **融資使用率控制在30%以下**：不要把額度用到滿
2. **設定強制停損線**：維持率低於140%就減碼，不要等追繳
3. **分散標的**：不要全壓單一股票，一檔斷頭拖垮整戶
4. **避開高融資使用率個股**：使用率>40%的股票少碰
5. **注意除權息假追繳**：除息日前算好維持率變化

### 觀察他人的斷頭訊號（反向操作）

- 大盤融資維持率驟降至130%附近 → 全市場恐慌 → 等量縮紅K是買點
- 個股融資餘額暴減40%以上 → 斷頭清洗完成 → 觀察法人是否承接
- 融資使用率從高位急降 → 散戶出場 → 可能是底部區
