# 融資活動現金流判讀：看懂公司的金脈來源與去向

**來源**：綜合 StockFeel、市場先生、IFRS準則等資料整理
**日期**：2026-05-19
**主題**：基本面分析

---

## 一、融資活動現金流是什麼？

融資活動現金流（Cash Flow from Financing Activities, CFF），又稱籌資活動現金流，是現金流量表三大現金流之一，記錄公司與資金提供者（股東、債權人）之間的現金往來。

簡單說：**融資活動現金流看的是「公司怎麼找錢，又怎麼還錢」**。

現金流量表三大現金流比較：
- **營業現金流（OCF）**：本業賺的錢 → 最重要
- **投資現金流（ICF）**：投資花的錢 → 通常為負
- **融資現金流（CFF）**：借錢、還錢、發股利 → 看金脈來源

## 二、融資活動現金流的組成項目

### 現金流入項目（向外部取錢）

1. **現金增資發行新股**：向投資人募集資金，公司收到現金
2. **舉債借款**：向銀行或金融機構借款（短期借款、長期借款）
3. **發行公司債**：在資本市場發行債券募集資金
4. **庫藏股出售**：買回的庫藏股再賣出（少見）

### 現金流出項目（把錢還給外部）

1. **發放現金股利**：把盈餘分配給股東（最重要且最常見的流出）
2. **償還借款**：還銀行錢、到期公司債還本
3. **買回庫藏股**：在公開市場買回自家股票
4. **少數股東取得股利**：非控制權益分配的股利

### IFRS下的分類差異

| 項目 | IFRS分類 | 台灣常見分類 |
|------|---------|-------------|
| 利息支出 | 可選擇歸入營業或融資 | 通常歸入營業 |
| 利息收入 | 可選擇歸入營業或投資 | 通常歸入營業 |
| 股利收入 | 可選擇歸入營業或投資 | 通常歸入營業 |
| 股利支付 | 歸入融資 | 歸入融資 |

⚠️ **注意**：台灣實務上，利息支出多數公司歸入營業現金流（因為是本業成本），但IFRS允許歸入融資現金流，閱讀時要注意分類差異！

## 三、融資活動現金流的四大判讀模式

### 模式一：CFF為負值（最常見的健康型態）

**含義**：公司把賺來的錢分配給股東或償還債務

常見組成：
- 發放現金股利（最大流出項）
- 償還借款
- 可能買回庫藏股

**判讀重點**：
- 如果OCF穩定正數且CFF為負（主要因為配息），→ ✅ 健康成熟公司
- 如果OCF為負，CFF為正（靠借錢度日），→ ⚠️ 大量舉債維持營運，危險
- 如果CFF長期為零，→ 公司既不配息也不擴張，可能缺乏成長動能

**實例**：台積電2024年融資現金流淨流出2,000多億，主要因為發放現金股利，這是健康的「把賺的錢回饋股東」

### 模式二：CFF為正值（公司正在找錢）

**含義**：公司從外部取得資金

常見原因：
1. **成長期公司擴張**：需要大量資金投入，本業利潤不夠支應
2. **舉新債還舊債**：借錢還錢，可能是正常周轉也可能是財務吃緊
3. **現金增資**：向股東要錢，稀釋每股盈餘
4. **財務吃緊**：本業賺不到錢，只能靠借錢度日

**判讀重點**：
- 區分「主動融資」vs「被動融資」
- 主動融資：有成長機會，OCF為正但仍需額外資金擴張
- 被動融資：OCF為負，靠借錢撐著

### 模式三：CFF持續大額正數（持續舉債）

**⚠️ 危險訊號**：
- 如果OCF長期為負 + CFF長期為正 = 借錢度日
- 觀察借款利率與OCF的關係：如果利息支出占OCF比>30%，還款壓力大
- 注意資產負債比是否飆升

### 模式四：CFF持續大額負數但不是配息

**可能含義**：
- 大量償還借款（如果OCF能支應，是降低槓桿的好事）
- 大量買回庫藏股（如果股價低估是好事，如果只是護盤是壞事）
- 發放特別股股利（注意特別股條款）

## 四、三大現金流組合判讀

### 「OCF+/ICF-/CFF-」：最健康的現金流組合

| 現金流 | 方向 | 含義 |
|--------|------|------|
| OCF | + | 本業賺錢 |
| ICF | - | 投資未來 |
| CFF | - | 配息還債 |

這是成熟穩定公司的典型現金流組合。台積電、鴻海等大型穩定企業多屬此類。

### 「OCF+/ICF-/CFF+」：成長期公司

| 現金流 | 方向 | 含義 |
|--------|------|------|
| OCF | + | 本業賺錢 |
| ICF | - | 大量投資 |
| CFF | + | 需要外部資金 |

本業開始賺錢，但投資需求太大，需要額外融資。觀察重點：融資用途是否明確、投資報酬率是否合理。

### 「OCF-/ICF-/CFF+」：危險組合

| 現金流 | 方向 | 含義 |
|--------|------|------|
| OCF | - | 本業虧錢 |
| ICF | - | 仍在投資 |
| CFF | + | 借錢度日 |

⚠️ 這是最危險的組合。公司本業虧損、積極投資、靠借錢維持。如果ICF是變賣資產（正數），情況更危險。

### 「OCF+/ICF+/CFF-」：收縮型態

| 現金流 | 方向 | 含義 |
|--------|------|------|
| OCF | + | 本业賺錢 |
| ICF | + | 變賣資產 |
| CFF | - | 還債配息 |

公司在收縮，變賣資產還債。如果是主動瘦身降低槓桿可能是好事，如果是被迫出售則需警惕。

## 五、融資活動現金流進階判讀指標

### 1. 股利支付率（Payout Ratio）

股利支付率 = 現金股利 / 營業現金流

- <30%：保守配息，保留現金投入成長
- 30%-70%：穩健配息，兼顧股東回報與公司發展
- >70%：高配息，可能吃掉投資資金
- >100%：⚠️ 借錢配息或吃老本

### 2. 自由現金流股利覆蓋率

FCF股利覆蓋率 = 自由現金流 / 現金股利

- >2倍：配息安全無虞
- 1-2倍：尚可但需監控
- <1倍：⚠️ 配息超過自由現金流，不可持續

### 3. 借款淨變化判讀

- 借款增加 > OCF成長 → 槓桿上升，注意偿債壓力
- 借款減少 + OCF穩定 → 降低槓桿，財務體質改善
- 短期借款增 > 長期借款增 → ⚠️ 矟債長投的危險訊號

### 4. 庫藏股買回判讀

庫藏股買回的融資現金流出：
- 股價低估時買回 → ✅ 善用公司資金
- 股價高估時買回 → ❌ 破壞股東價值
- 護盤性質買回 → 通常效果不佳
- 觀察買回均價vs執行率判断真假

### 5. 現金增資稀釋效果

現金增資的融資現金流入：
- 增資股數稀釋比 = 新增股數 / 原流通股數
- 稀釋比>10%：顯著稀釋，需關注增資用途與預期報酬
- 每股淨值變化：增資價>每股淨值為正面，增資價<每股淨值為負面

## 六、融資活動現金流常見陷阱

### 陷阱1：借錢配息

表面配息率很高，但OCF不足以支應，實際上是借錢來配息。

**辨識方法**：
- CFF中的借款增加 ≈ 現金股利發放
- OCF/現金股利 < 1
- 配息率>100%但OCF為負或極低

### 陷阱2：短債長投

用短期借款支應長期投資，到期時若無法續借會陷入周轉危機。

**辨識方法**：
- ICF大額負數（長期投資）+ CFF中大額短期借款
- 短期負債/總負債比持續上升
- 流動比率<1.5

### 陷阱3：庫藏股護盤

管理層買回庫藏股宣稱「股價低估」，實際只是護盤或掩護特定人出貨。

**辨識方法**：
- 買回期間股價未見支撐效果
- 買回均價高於買回期間均價
- 買回後減資vs轉讓員工比例

### 陷阱4：持續融資稀釋

公司持續辦理現金增資，不斷稀釋原有股東權益。

**辨識方法**：
- 連續數年CFF為正，主要來源是現金增資
- EPS持續被稀釋
- 增資用途模糊或效益不明

## 七、台股實戰判讀範例

### 範例1：台積電（穩健成熟型）
- OCF：大額正數（本業賺大錢）
- ICF：大額負數（持續擴廠投資）
- CFF：負數（主要為發放現金股利+償還借款）
- 判讀：✅ 健康成熟企業的典型現金流組合

### 範例2：新創生技股（成長期型）
- OCF：負數（研發階段尚未獲利）
- ICF：負數（研發投入+實驗室設備）
- CFF：正數（現金增資+借款支應）
- 判讀：⚠️ 需觀察現金消耗率（Cash Burn Rate），關注何時OCF轉正

### 範例3：高負債企業（危險型）
- OCF：小幅正數或負數
- ICF：小額負數
- CFF：大額正數（持續舉債）
- 判讀：❌ 借錢度日，需觀察利息支出占OCF比、負債比率趨勢

## 八、融資活動現金流判讀SOP

### 五步判讀法

1. **看CFF正負**：正數=公司在找錢，負數=公司在還錢/配息
2. **拆解組成**：是配息？還債？增資？買回庫藏股？各占多少？
3. **看OCF支應能力**：OCF能否支應CFF的流出？
4. **追蹤趨勢**：連續3-5年的CFF變化趨勢
5. **交叉驗證**：搭配負債比、利息保障倍數、股利支付率綜合判斷
