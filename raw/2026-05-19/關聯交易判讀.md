# 關聯交易判讀：看穿集團企業間的利益輸送

**來源**：AI 整理（參考公開資訊觀測站、IFRS 24、台灣證交所揭露規範）
**日期**：2026-05-19
**主題**：基本面分析

---

## 一、什麼是關聯交易？

關聯交易（Related Party Transactions）是指公司與其關聯方之間的交易，包括：

1. **母子公司交易**：集團內部母公司與子公司之間的買賣
2. **兄弟公司交易**：同一母公司下的不同子公司之間
3. **董事/大股東交易**：公司與董監事、大股東及其家族企業的交易
4. **關鍵管理人員交易**：與高階經理人及其親屬的交易

### 為什麼要判讀關聯交易？

- 關聯交易可能影響財報真實性
- 利益輸送可能損害少數股東權益
- 集團企業的獲利可能來自內部交易而非外部競爭力
- 關聯交易佔比過高是財報防雷的重要警訊

## 二、IFRS 24 關聯方揭露規範

台灣自 2013 年起採用 IFRS 24「關聯方揭露」，要求企業在財報中揭露：

### 必須揭露的關聯方關係

| 關聯方類型 | 判定標準 | 範例 |
|-----------|---------|------|
| 母公司 | 直接或間接控制 | 持股超過50% |
| 子公司 | 被控制 | 母持股超過50% |
| 關聯企業 | 具重大影響力 | 持股20%-50% |
| 合資企業 | 共同控制 | 雙方各持50% |
| 關鍵管理人員 | 有決策權 | 董事、總經理 |
| 近親 | 親屬關係 | 配偶、二親等內 |

### 必須揭露的交易類型

1. 進貨交易金額與比例
2. 銷貨交易金額與比例
3. 資金往來（借款、背書保證）
4. 資產交易（不動產、設備）
5. 技術授權與勞務交易
6. 薪資報酬（董監事酬金）

## 三、關聯交易的五種利益輸送手法

### 1. 進銷貨操縱——虛增營收或移轉利潤

**手法**：母公司以高於市價向子公司進貨（利潤留母公司），或以低於市價向子公司銷貨（利潤轉移到子公司）

**判讀重點**：
- 關聯進銷貨佔總進銷貨比例 >30% 需警覺
- 比較關聯交易單價與非關聯交易單價差異
- 關聯交易毛利率異常偏高或偏低

### 2. 資金往來——無息或低息借款

**手法**：母公司向子公司無息借款（子公司承擔資金成本），或以高利率借款給子公司（利潤轉移到母公司）

**判讀重點**：
- 資金往來金額佔淨值比例 >5% 需注意
- 借款利率明顯偏離市場利率
- 關聯資金往來是否有合理商業目的

### 3. 背書保證——替關聯方擔保風險

**手法**：公司替關聯方背書保證，承擔或有負債風險

**判讀重點**：
- 背書保證金額佔淨值比例 >50% 需警戒
- 被保證對象的財務狀況
- 保證目的是否有商業合理性

### 4. 資產交易——賤賣或貴買

**手法**：以低價出售資產給關聯方（利益輸出），或以高價向關聯方購買資產（利益輸入）

**判讀重點**：
- 不動產交易是否有獨立估價報告
- 交易價格是否偏離公告現值或帳面值太多
- 無形資產（專利、商標）授權金是否合理

### 5. 薪資酬金——董監事酬金過高

**手法**：透過董監事酬金、顧問費等方式將利潤分配給特定人

**判讀重點**：
- 董監事酬金佔稅後淨利比例 >5% 偏高
- 比較同業同規模公司酬金水準
- 關鍵管理人員是否同時在多家關聯公司領薪

## 四、關聯交易判讀五步法

### Step 1：看揭露完整度

檢查財報附註中關聯方揭露是否完整：
- 關聯方清單是否齊全
- 是否有未揭露的關聯交易
- 揭露金額是否合理（與營收規模比較）

### Step 2：計算關聯交易佔比

計算關鍵比率：
- 關聯進貨佔總進貨比率
- 關聯銷貨佔總銷貨比率
- 關聯資金往來佔淨值比率
- 關聯背書保證佔淨值比率

### Step 3：比較價格合理性

- 比較關聯 vs 非關聯交易的單價
- 比較毛利率差異
- 比較借款利率與市場利率

### Step 4：分析趨勢變化

- 關聯交易比例是否逐年上升
- 是否在獲利下滑時增加關聯交易
- 關聯方是否新增或減少

### Step 5：交叉驗證

- 合併報表 vs 個別報表的差異
- 關聯交易是否在合併報表中消除
- 少數股東權益變化是否合理

## 五、關聯交易紅旗清單

🔴 **嚴重紅旗**（碰了就跑）：
- 關聯銷貨佔比 >50%
- 關聯進貨佔比 >70%
- 關聯資金往來金額 >淨值50%
- 背書保證金額 >淨值100%
- 與關聯方不動產交易無獨立估價

🟡 **黃旗警告**（深入調查）：
- 關聯交易佔比 30-50%
- 關聯方毛利率明顯偏離同業
- 關聯交易在獲利下滑時突然增加
- 董監事酬金佔淨利 >5%

🟢 **綠旗安全**（持續觀察）：
- 關聯交易佔比 <20%
- 交易條件與非關聯方一致
- 有獨立第三方估價
- 合併報表中關聯交易已適當消除

## 六、台股常見的集團關聯交易案例

### 食品集團——統一企業

- 統一企業與統一超商的進銷貨交易
- 關聯進貨佔比約 15-20%，但交易條件相對透明
- 合併報表中適當消除

### 電子集團——鴻海

- 鴻海集團內部關聯交易金額龐大
- 但因業務複雜度，關聯交易有其合理性
- 需注意是否有利益輸送至未上市關聯企業

### 金融集團——國泰金控

- 國泰人壽與國泰世華銀行的資金往來
- 金融集團關聯交易需符合金管會規範
- 注意關聯放款條件是否優於一般客戶

## 七、揭露管道與實戰查詢方法

### 公開資訊觀測站

1. **財務報告** → 財報附註「關聯方交易」專章
2. **年報** → 關聯方交易揭露
3. **重大訊息** → 關聯交易公告
4. **背書保證** → 背書保證明細查詢

### 實戰查詢步驟

1. 下載公司財報，搜尋「關聯方」或「關係人」
2. 找到關聯方交易金額和比例
3. 對比合併報表中的消除數
4. 計算關聯交易佔總營收/總進貨的比例
5. 與同業比較關聯交易佔比
