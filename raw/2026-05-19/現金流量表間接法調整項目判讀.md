## 現金流量表間接法的基本原理

間接法（Indirect Method）是編制現金流量表「營業活動現金流」最常用的方法，台灣上市櫃公司超過 95% 採用間接法。

### 間接法的核心邏輯

從「稅後淨利」（會計利潤）出發，逐步調整回「營業活動現金流量」（實際現金流入流出）：

**稅後淨利** → 加回非現金支出 → 調整營運資金變動 → **營業活動現金流量**

為什麼需要調整？因為：
- 損益表認列的收入不等于當期收到的現金（應收帳款）
- 損益表認列的費用不等于當期支付的現金（應付帳款、折舊）
- 有些損益表項目根本沒有現金流（折舊、攤銷）

### 間接法調整項目分類

| 類別 | 項目 | 調整方向 | 原因 |
|------|------|----------|------|
| 非現金支出 | 折舊 | ＋加回 | 帳面費用但無現金流出 |
| 非現金支出 | 攤銷 | ＋加回 | 帳面費用但無現金流出 |
| 非現金支出 | 資產減損 | ＋加回 | 帳面損失但無現金流出 |
| 非現金收入 | 投資收益（權益法） | －扣除 | 帳面收益但無現金流入 |
| 非營業項目 | 出售資產利益 | －扣除 | 歸屬投資活動 |
| 非營業項目 | 出售資產損失 | ＋加回 | 歸屬投資活動 |
| 非營業項目 | 利息收入 | －扣除 | 歸屬投資/營業活動 |
| 營運資金 | 應收帳款增加 | －扣除 | 錢沒收到 |
| 營運資金 | 應收帳款減少 | ＋加回 | 收到前期應收 |
| 營運資金 | 存貨增加 | －扣除 | 錢花在買存貨 |
| 營運資金 | 存貨減少 | ＋加回 | 賣掉前期存貨 |
| 營運資金 | 應付帳款增加 | ＋加回 | 錢還沒付 |
| 營運資金 | 應付帳款減少 | －扣除 | 付掉了前期應付 |

## 非現金支出的深度判讀

### 折舊與攤銷

折舊和攤銷是最常見的加回項目，但投資者要注意：

1. **折舊加回不等於公司有等額現金可用**
   - 折舊加回只是「帳面上加回去」，實際現金在當初購買資產時就已經付出了
   - 加回折舊是為了還原「折舊已從淨利中扣除」的事實

2. **折舊金額的實戰意義**
   - 折舊金額接近「資本維持支出」的近似值
   - 自由現金流 = 營業現金流 - 資本支出，但如果資本支出 ≈ 折舊，表示公司只做維持性投資
   - 資本支出 >> 折舊，代表公司正在擴張

3. **折舊政策的變更**
   - 延長耐用年限 → 折舊減少 → 淨利增加（但現金流沒變）
   - 這是合法的盈餘管理手段，投資者要看現金流而非淨利

### 資產減損

減損是最容易被忽略的加回項目：

- **減損認列**：帳面認列損失，淨利大降
- **間接法加回**：營業現金流不受影響
- **投資者必須做的事**：看扣除減損後的「正常化現金流」，而非被減損扭曲的單一期間數字

### 權益法投資收益

被投資公司賺錢時，投資公司按持股比例認列投資收益：
- 帳面上有收益（淨利增加）
- 但可能沒有收到現金（沒有配息）
- 間接法必須扣除這筆「沒收到現金的收益」

**實戰判斷**：
- 權益法投資收益佔淨利比 > 30%：要小心盈餘品質
- 現金股利發放率低的公司，權益法收益更要注意

## 營運資金變動的深度判讀

營運資金變動是間接法最關鍵也最容易出問題的部分。

### 應收帳款變動

**應收帳款增加（扣除項）的兩種解讀**：
1. **良性增加**：營收成長帶動應收帳款自然增加，成長型公司常見
2. **惡性增加**：收款天數拉長，客戶付款能力下降，壞帳風險上升

**判斷方法**：
- 應收帳款增加率 vs 營收增加率
  - 應收帳款增加率 > 營收增加率 → 紅旗🚩
- 應收帳款週轉天數（DSO）趨勢
  - DSO 上升 = 收款變慢 = 紅旗🚩

### 存貨變動

**存貨增加（扣除項）的三種解讀**：
1. **備貨型增加**：預期銷售成長，提前備貨
2. **滯銷型增加**：賣不出去的存貨堆積
3. **策略型增加**：原物料價格低時大量進貨（如面板廠搶料）

**判斷方法**：
- 存貨增加率 vs 營收增加率
  - 存貨增加率 >> 營收增加率 → 可能滯銷🚩
- 存貨結構分析
  - 成品存貨增加 > 原物料增加 → 滯銷風險高🚩
  - 原物料增加 > 成品增加 → 可能是策略備貨

### 應付帳款變動

**應付帳款增加（加回項）的兩種解讀**：
1. **良性增加**：公司議價能力強，延後付款是免費融資
2. **惡性增加**：公司現金不足，付不出錢

**判斷方法**：
- 應付帳款週轉天數（DPO）趨勢
- 現金流量表「支付供應商現金」是否正常
- 供應商結構（集中度高時議價能力弱，DPO 不可能太高）

## 間接法實戰判讀框架

### 框架一：現金流品質三維檢查

| 維度 | 健康訊號 | 危險訊號 |
|------|----------|----------|
| 非現金調整 | 折舊攤銷穩定 | 減損大幅波動 |
| 營運資金 | 應收帳款與營收同步成長 | 應收帳款增速遠超營收 |
| 整體品質 | 營業現金流 > 淨利 | 營業現金流 < 淨利 |

### 框架二：營運資金變動健康度

1. **流動資產變動 = 應收帳款 + 存貨 - 預付費用**
   - 流動資產增加 > 營收成長 → 紅旗
   - 流動資產增加 ≈ 營收成長 → 正常

2. **流動負債變動 = 應付帳款 + 預收收入**
   - 流動負債增加 → 供應商融資（好）
   - 流動負債減少 → 加速付款（看現金壓力）

3. **淨營運資金變動 = 流動資產變動 - 流動負債變動**
   - 淨營運資金增加 → 現金被綁住（扣減項）
   - 淨營運資金減少 → 現金被釋放（加回項）

### 框架三：間接法異常偵測

**異常一：折舊攤銷異常偏低**
- 可能變更折舊政策延長耐用年限
- 可能採用過於樂觀的殘值估計
- 比較同行業公司折舊率判斷合理性

**異常二：營運資金變動方向矛盾**
- 營收成長但應收帳款減少 → 可能轉讓應收帳款
- 營收衰退但存貨增加 → 滯銷堆積🚩
- 應付帳款突然暴增 → 可能付不出錢🚩

**異常三：非營業項目金額過大**
- 處分資產利益/損失佔淨利 > 20% → 本業獲利能力存疑
- 權益法投資收益佔淨利 > 30% → 現金可能沒進來🚩

## 台積電間接法判讀實戰案例

以台積電2024Q4現金流量表為例：

### 非現金調整項目
- 折舊及攤銷：約 1,500 億（加回）
- 權益法投資收益：約 50 億（扣除）
- 處分資產利益：約 10 億（扣除）

### 營運資金變動
- 應收帳款減少：約 200 億（加回）→ 收款效率提升
- 存貨增加：約 300 億（扣除）→ 先進製程備貨
- 應付帳款增加：約 100 億（加回）→ 供應鏈議價力強

### 關鍵判讀
1. 折舊攤銷 金額大 → 代表資本支出龐大，需關注資本支出/折舊 比率
2. 權益法收益 扣除 → 確保不被未實現收益虛增淨利
3. 應收帳款 減少 → 收款品質好，營運資金管理佳

## 五個常見誤區

### 誤區一：折舊加回 = 公司有現金可用
- 錯！折舊加回只是還原帳面扣除
- 實際現金早在購買資產時已付出
- 加回折舊的意義是「這筆費用沒有實際現金流出」

### 誤區二：營業現金流 > 淨利 = 盈餘品質好
- 不一定！要看調整項目的結構
- 如果是靠應付帳款大幅增加（拖欠供應商）→ 不可持續
- 如果是靠折舊攤銷加回 → 這是正常的

### 誤區三：間接法數字和直接法一樣
- 營業現金流總額一樣，但分類可能不同
- 間接法從淨利調整，看不到現金流源頭
- 直接法列出現金收入和支出，資訊更透明但編制複雜

### 誤區四：營運資金變動是投資者的錯覺
- 營運資金變動直接影響現金流
- 應收帳款暴增 = 公司收不到錢 = 紅旗🚩
- 存貨暴增 = 賣不出去 = 紅旗🚩

### 誤區五：減損加回後就不用管減損
- 減損雖然不影響現金流，但影響資產品質
- 減損意味著資產不值原先認列的價值
- 連續減損的公司，資產負債表可能嚴重失真
