# 現金股利與股票股利差異與選擇策略

**來源**：AI 整理（參考公開資訊觀測站、證交所除權息制度、台灣稅法）
**日期**：2026-05-19
**主題**：基本面分析

---

## 一、現金股利與股票股利的基本差異

| 比較項目 | 現金股利 | 股票股利 |
|---------|---------|---------|
| 發放形式 | 現金（每股配多少元） | 股票（每股配多少股） |
| 對股東權益 | 總值不變（現金增加、股價除息下降） | 總值不變（股數增加、股價除權下降） |
| 對公司現金 | 流出（減少現金） | 不影響（保留現金在公司） |
| 對股本 | 不影響 | 增加股本 |
| 對EPS | 不影響 | 稀釋（股數增加分母變大） |
| 對ROE | 不影響 | 稀釋（淨值不變但股本膨脹） |
| 稅務影響 | 併入綜所稅、二代健保 | 免稅（不計入股利所得） |
| 填權息難度 | 填息（需股價漲回除息前價格） | 填權（需股價漲回除權前價格） |

### 現金股利（Cash Dividend）

- 公司把賺到的盈餘以現金形式分配給股東
- 每股配息 X 元：假設每股市價 100 元，配息 5 元，除息後參考價為 95 元
- 對股東：拿到 5 元現金，但持股總值 = 95 + 5 = 100 元（不變）
- 對公司：現金減少 5 元/股，但保留盈餘也減少

### 股票股利（Stock Dividend）

- 公司把盈餘轉增資，以股票形式分配給股東
- 每股配股 X 元：假設每股面值 10 元，配股 2 元（= 0.2 股/每股），持有 1000 股變成 1200 股
- 對股東：股數增加但股價等比例下降，持股總值不變
- 對公司：現金沒有流出，股本膨脹

## 二、除權息的數學計算

### 除息參考價

```
除息參考價 = 除息前收盤價 - 每股現金股利
```

範例：收盤價 100 元，每股配息 5 元
- 除息參考價 = 100 - 5 = 95 元

### 除權參考價

```
除權參考價 = 除權前收盤價 / (1 + 每股配股比例)
```

範例：收盤價 100 元，每股配股 2 元（= 0.2 股）
- 除權參考價 = 100 / (1 + 0.2) = 83.33 元

### 同時除權息參考價

```
除權息參考價 = (除權前收盤價 - 每股現金股利) / (1 + 每股配股比例)
```

範例：收盤價 100 元，每股配息 3 元 + 配股 2 元（= 0.2 股）
- 除權息參考價 = (100 - 3) / (1 + 0.2) = 80.83 元

## 三、現金股利 vs 股票股利的公司意圖

### 偏好現金股利的公司——成熟穩定

1. **現金流充裕**：業務穩定，不需大量資本支出
2. **不需要保留盈餘再投資**：成長率趨緩
3. **照顧股東現金需求**：適合存股族、退休族
4. **向市場傳遞信心**：願意真金白銀分配

**代表產業**：金融股、電信股、中華電、統一超

### 偏好股票股利的公司——成長擴張

1. **現金流緊繃**：需要保留現金投入擴張
2. **資本支出需求大**：半導體、面板等重資本產業
3. **盈餘再投資報酬率高**：保留盈餘能創造更高 ROE
4. **稀釋效應被忽視**：投資人只看配股不看稀釋

**代表產業**：IC設計、生技、新興科技股

### ⚠️ 警惕：高股票股利可能隱藏的問題

- 連年配股票不配現金 → 公司可能現金不夠或大股東想稀釋散戶
- 大股東拿現金、散戶拿股票 → 利益不對等
- 股本膨脹速度 > 獲利成長速度 → EPS 被稀釋，真正的成長被掩飾

## 四、稅務考量——現金股利 vs 股票股利

### 現金股利課稅

1. **綜合所得稅**：股利所得併入綜所稅申報
   - 方案一：合併計稅（併入綜所稅，適用邊際稅率）
   - 方案二：分離課稅（股利 × 28% 就好）

2. **二代健保補充保費**：
   - 單筆股利 > 20,000 元，扣 2.11%
   - 注意：是「單筆」不是全年合計

### 股票股利課稅

1. **配股當下免稅**：不計入股利所得
2. **賣出時才課稅**：以面值 10 元計入成本，賣出時的價差計入證券交易所得
3. **二代健保**：配股當下不扣，但面值合計 > 20,000 元時仍需扣繳

### 稅務策略選擇

| 情境 | 偏好 | 原因 |
|------|------|------|
| 高所得者（邊際稅率 >30%）| 股票股利 | 避免現金股利被高稅率課稅 |
| 低所得者（邊際稅率 <20%）| 現金股利 | 享受較低稅率且有現金流 |
| 大量持股者 | 現金股利 | 避免股本膨脹稀釋控制權 |
| 小額投資者 | 看填權息機率 | 填息機率高的選現金，填權機率高的選股票 |

## 五、填權息機率的實戰判斷

### 填息成功率高的情况

1. **基本面佳**：營收成長、獲利穩定、展望正面
2. **籌碼面好**：外資/投信連續買超、融資減少
3. **殖利率合理**：5-7% 區間最容易填息
4. **歷史填息紀錄好**：過去3年填息成功率 >70%

### 填權成功率高的情况

1. **成長股**：隔年 EPS 成長率高於股本膨脹率
2. **市場多頭**：多頭市場填權意願高
3. **低股本股**：股本膨脹比例低（如配0.5元 vs 配3元）

### 📊 歷史數據參考

- 台股整體填息成功率約 65-75%（多頭年份可達 80%+）
- 填權成功率低於填息（因為股本膨脹壓力）
- 高殖利率股（>8%）填息成功率反而偏低（可能股價弱勢）

## 六、投資人選擇策略

### 策略一：參加除息（拿現金）

**適合條件**：
- 短期不想賣股
- 需要現金流（退休族）
- 稅率低於 28%（選合併計稅）
- 公司歷史填息紀錄佳

**風險**：
- 除息後股價可能不填息（帳面虧損）
- 高殖利率陷阱（公司體質不佳）
- 二代健保補充保費（單筆 >2 萬）

### 策略二：棄息（除息前賣出）

**適合條件**：
- 高所得者（稅率 >30%）
- 預期除息後股價跌、不填息
- 單筆股利 >20 萬（二代健保扣很多）

**做法**：在除息基準日前最後交易日賣出，除息後再買回
**風險**：買回價格可能高於賣出價（賺了股利但賠了價差）

### 策略三：參加除權（拿股票）

**適合條件**：
- 看好公司成長性
- 公司 ROE > 配股率稀釋效果
- 市場多頭，填權機率高
- 想避免現金股利的高稅率

**風險**：
- 股本膨脹稀釋 EPS
- 公司ROE下降時，配股越多稀釋越嚴重
- 填權失敗 = 帳面虧損

### 策略四： ETF 替代策略

**做法**：買高股息 ETF（如 0056、00878）取代個股除息
**優點**：分散風險、避免個股不填息
**缺點**：管理費、ETF 本身也扣二代健保

## 七、除權息季節實戰日曆

### 台股除權息時間軸

1. **3-4月**：股東會公告除權息日期
2. **5-6月**：除權息旺季開始（小型股先，大型股後）
3. **7-8月**：大型權值股除息（台積電、鴻海）
4. **9月**：除權息尾聲

### 關鍵日期順序

```
宣告日 → 除權息基準日 → 最後過戶日 → 停止過戶日 → 除權息交易日 → 發放日
```

- **宣告日**：董事會決議配發金額
- **除權息交易日**：當天買進不享配息配股
- **最後過戶日**：這天賣出仍享配息配股
- **發放日**：現金/股票實際入帳

## 八、常見錯誤與陷阱

### 錯誤一：高殖利率就是好股票

- 殖利率 = 現金股利 / 股價，殖利率高可能是因為股價跌太多
- 資本利得損失可能遠大於股利收入
- 應該看「殖利率 + 股價成長」的總報酬

### 錯誤二：配股票比配現金好（因為不用繳稅）

- 配股票看似免稅，但股本膨脹稀釋 EPS
- 如果公司 ROE 不高，配股票反而不利
- 出售配股時的證交稅 + 所得稅也不能忽略

### 錯誤三：除息前一天買就可賺股利

- 除息後股價會扣減股息金額
- 如果不填息，等於左手拿股利、右手賠價差
- 加上稅金和手續費，可能反而虧損

### 錯誤四：股本膨脹沒關係，反正有配股

- 配股2元 = 股本膨脹20%（面值10元計算）
- 若隔年EPS成長 < 20%，EPS反而下降
- 連年高配股是慢性稀釋
